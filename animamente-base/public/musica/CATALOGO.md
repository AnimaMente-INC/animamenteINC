# Músicas de fundo (CC0 — sem copyright)

Todas as faixas desta pasta são **CC0 1.0 (domínio público)**: uso livre em qualquer vídeo, inclusive monetizado, **sem precisar dar crédito**.
Origem: repositório https://github.com/uncle-sheepsky/duru-ai-cc0-bgm (licença CC0 conferida no `LICENSE` do repositório; texto em `LICENCA-CC0.txt` aqui).
As faixas `animada-1/2/3` são geradas pelo próprio projeto (`scripts/gerar-musica.py`).

Todas foram convertidas para MP3 128 kbps e **normalizadas para o mesmo volume** das `animada-*` (-14,5 LUFS), então o volume do vídeo (`audio.volumeMusica`) vale para todas.
Faixas curtas (até ~1:05) repetem em loop automaticamente.

Como usar: no roteiro, `"musica": "<nome>"` (o nome do arquivo sem `.mp3`).

## Qual escolher
- **Games / retrô / tecnologia:** `arcade-rondo`, `arcade-vibe`, `denparcade`, `ritmo-febre`, `korobeiniki-arcade`, `korobeiniki-boombap`, `puzzle-2048`, `jogo-de-ritmo`
- **Tensão / suspense leve / corrida:** `rei-da-montanha`, `desvio-veloz`
- **Humor / curiosidades:** `polka`, `marcha-engracada`, `charleston`, `jiga`
- **Leve / explicação calma:** `frutinhas`, `assobio`, `arcade-inverno`, `calipso`, `ska`
- Varie: não repita a mesma música do vídeo anterior.

Observação: escolhi pela descrição de cada faixa; ouça uma vez antes de fixar a favorita.
